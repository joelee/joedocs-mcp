Search syntax

Words match titles, aliases and bodies, ignoring case, accents and word endings (plans matches plan). Title matches rank above body matches.

SyntaxMatches
rate limitdocuments with both words
"rate limit"the words in that order
-redisexcludes documents with the word
auth*words starting with auth
redis OR valkeyeither word

A search of exclusions only is refused. Without words, results are newest first.

Filters must all hold. key=value means equals. The JSON filters take an object keyed by front matter key, with a plain value or operators:

OperatorExample
eq, ne{"status": {"ne": "done"}}
in{"status": {"in": ["draft", "review"]}}
contains{"tags": {"contains": "security"}} (for lists)
gt, gte, lt, lte{"updated": {"gte": "2026-10-01"}}, {"priority": {"lte": 2}}
exists{"approved_by": {"exists": true}}

Text compares ignoring case, numbers as numbers, and dates as text, so prefixes such as 2026-10-01 work. Each file of a multi-file document is searched on its own, and filters apply to the front matter of the file that matched.
