Backup

Downloads the vault, the history and the database as one .tgz holding {{ documents }} documents, as joedocs backup writes it. Restore it on the server with joedocs backup --restore.

On the server only

These commands run in a terminal on the server; see the deployment guide.

  • joedocs init: create the vault, the history and the database.
  • joedocs serve and joedocs systemd install: run the server, by hand or as a service.
  • joedocs admin-token create: make the admin tokens this interface signs in with.
  • joedocs agents: print the guide for agents that use this server.
  • joedocs backup --restore: restore a backup into empty directories.
